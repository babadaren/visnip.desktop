# 解题面板设计（v1）

## 目标

截图工具栏新增「题」按钮。选定区域后点击「题」，截图遮罩关闭，屏幕侧边弹出一个常驻的解题面板。面板记住这个屏幕区域：用户随时点击「获取答案」（或按 F4），程序把该区域当前的画面截图，连同提示词发给用户配置的多模态大模型，并在面板中流式显示解题答案。

## 交互流程

1. F1 截图，选定题目区域，底部工具栏出现。
2. 点击工具栏「题」：遮罩关闭，面板弹出，顶部显示选区当时的画面。桌面恢复正常使用。
3. 点击面板「获取答案」或按 F4：
   - 截取该区域**此刻**的画面，替换面板顶部的预览图（所见即所发）；
   - 发送给大模型，答案逐字显示在下方；
   - 请求进行中按钮变为「停止」。
4. 「重新选定」：隐藏面板，打开截图遮罩并以当前区域作为初始选区；调整后再点「题」，面板更新区域。
5. 面板全程只有一个实例；再次从工具栏点「题」只会更新区域。
6. 关闭面板即结束本次解题会话，F4 同时注销。

补充规则：

- 只在点击时截图，不定时刷新。
- 截图时画的标注不会带入面板（面板用的是实时画面）。
- 长截图模式下「题」按钮禁用（与「翻译」一致）。
- 任何截图遮罩打开期间面板先隐藏，遮罩关闭后恢复，避免被拍进冻结的桌面图、避免两个置顶窗口互相遮挡。

## 面板界面

```
┌──────────────────────────────┐
│ 解题                ⚙  —  ✕ │  ← 标题栏：拖动移动；设置 / 收起 / 关闭
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │      选区预览图          │ │
│ └──────────────────────────┘ │
│ 820×360 · 12:03 截取  [重新选定]│
│ [      获取答案  F4      ]   │  ← 请求中变为「停止」
│ 思考中… 8s                   │  ← 状态行
├──────────────────────────────┤
│ 答案（Markdown 渲染）         │
│ …                            │
├──────────────────────────────┤
│ ‹ 3/5 ›            [复制答案]│  ← 最近几题的历史切换
└──────────────────────────────┘
```

- 窗口：无边框、置顶、Tool 窗口（不进任务栏），弹出时不抢焦点。
- 位置：默认停靠在选区所在屏幕的右侧；如果会挡住选区，改放左侧。可拖动标题栏移动，可在底角拖动调整大小。
- 「收起」只保留标题栏。
- 未配置模型时，答案区显示提示和「打开设置」按钮。
- 历史：保留最近 10 题（截图 + 答案 + 时间），只在内存中，关闭面板即清空。
- 点击「获取答案」时，如果面板被用户拖到了选区上方，截图前临时把面板设为透明，截完恢复，避免截到面板自己。
- 选区跨越多块屏幕时，只截取面积最大的那块屏幕上的部分，并在状态行提示。

## 首选项「解题」页

| 配置 | 说明 |
| --- | --- |
| 接口格式 | OpenAI 兼容（默认）/ Anthropic |
| 接口地址 | 基础地址或完整接口地址均可；留空使用各格式的官方地址 |
| API Key | 密码框，可切换显示；Windows 上用 DPAPI 加密后保存 |
| 模型 | OpenAI 兼容格式必填（须支持图片输入）；Anthropic 格式留空默认 `claude-opus-5-5` |
| 测试连接 | 发送一张极小的图片，验证地址、Key、模型和图片支持 |
| 专业范围 | 如「高中数学、大学物理」，会追加到提示词中 |
| 自定义提示词 | 多行；留空使用内置默认提示词（占位文字即默认内容），可「恢复默认」 |
| 请求超时 | 30–600 秒，默认 120 秒（指无数据传输的时长） |
| 跟随系统代理 | 默认开启，只作用于解题请求 |

快捷键页新增「获取答案（解题面板）」，默认 F4，仅在面板打开时注册。

## 提示词

最终发送的系统提示词 = （自定义提示词，为空则用默认提示词）+（专业范围非空时追加一句领域说明）。用户消息 = 截图 + 一句固定的「请解答图片中的题目」。

默认提示词要点：识别图片中的题目；先给最终答案，再给简要解题步骤；选择题写明选项；看不清或题目不完整时说明；**不要使用 LaTeX**，公式用 Unicode 符号书写（如 x²、√2、≤、π）。

由于模型仍可能输出 LaTeX，显示前对 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 内的常见 LaTeX 做一次 Unicode 化（分式、根号、上下标、希腊字母、常见运算符），代码块内不处理。QtWebEngine 在 MinGW 下不可用，所以不做完整的公式渲染。

## 接口

### OpenAI 兼容

- 地址：完整接口地址原样使用；以 `/v1` 等路径结尾的基础地址补 `/chat/completions`；只有域名的补 `/v1/chat/completions`。默认 `https://api.openai.com/v1/chat/completions`。
- 请求头：`Authorization: Bearer <key>`。
- 请求体：`model`、`stream: true`、`messages`（system 文本 + user 内容数组：`text` + `image_url`，图片为 `data:image/png;base64,…`）。不传 `max_tokens`，避免与各家的参数差异冲突。
- 流式：SSE `data:` 行，读取 `choices[0].delta.content`；`delta.reasoning_content` / `delta.reasoning` 视为思考过程（只用于显示「思考中」）；`data: [DONE]` 结束。

### Anthropic

- 地址：默认 `https://api.anthropic.com/v1/messages`；基础地址按需补 `/v1/messages`。
- 请求头：`x-api-key`、`anthropic-version: 2023-06-01`。
- 请求体：`model`、`max_tokens: 16000`、`stream: true`、`system`、`messages`（user 内容：先 `image`（base64 源），后 `text`）。不传 `thinking`，由模型默认行为决定。
- 当地址是官方 `api.anthropic.com` 且模型支持时（`claude-fable-5-1`、`claude-opus-5-5`、`claude-opus-5`、`claude-sonnet-5-5`），附加服务端降级：请求头 `anthropic-beta: server-side-fallback-2026-07-01`、请求体 `fallbacks: "default"`。安全分类器拒答时由服务端在同一个流里换模型继续。第三方 Anthropic 兼容接口不附加这两项。
- 流式：`content_block_delta` 中 `text_delta` 为正文，`thinking_delta` 视为思考；`message_delta.delta.stop_reason` 为 `refusal` 时提示「模型拒绝回答」；`error` 事件报错；`ping` 忽略。

### 通用

- 服务端忽略 `stream` 直接返回 JSON 时，按非流式格式解析。
- HTTP 错误解析 `error.message` 转成可读提示（401 Key 无效、404 地址或模型不存在、429 频率/额度、模型不支持图片等）。
- 新请求会取消上一次未完成的请求；「停止」立即中断。

## 截图与图片

- 选区以全局逻辑坐标记录。点击时找面积最大的那块屏幕，用 `QScreen::grabWindow(0)` 抓整屏再按屏幕的像素比裁剪，得到物理分辨率的清晰图（与现有 Qt 截图回退路径相同）。
- 发送前：长边超过 2000px 缩小到 2000px；长边小于 400px 放大 2 倍（小字识别更好）；PNG 编码，超过 3.5MB 改用 JPEG（质量 90）。

## 安全与隐私

- API Key：Windows 上用 DPAPI（`CryptProtectData`，当前 Windows 用户范围）加密，以 `dpapi:` 前缀存入配置；读到旧的明文值时照常使用，下次保存自动加密。
- 面板不设置「屏幕捕获排除」属性，录屏和屏幕共享中可见。截到面板自己的问题靠位置避让和截图时临时透明解决。
- 截图只在用户点击时发送到用户自己配置的接口。

## 代码结构

| 模块 | 位置 | 内容 |
| --- | --- | --- |
| 配置 | `core/AppConfig` | `QuestionSettings`、F4 快捷键、读写与 DPAPI |
| 请求与解析 | `core/QuestionAnswer` | 提示词拼装、地址归一化、请求体构造、流式/非流式/错误解析、LaTeX Unicode 化、图片编码 |
| 网络服务 | `services/QuestionAnswerService` | 发送、流式回调、取消、超时、代理、测试连接 |
| 面板 | `ui/question/QuestionPanel` | 面板界面、区域截图、历史 |
| 接入 | `CompactToolbar`、`CaptureOverlayWindow`、`AppController`、`SettingsDialog`、`HotkeyManager` | 「题」按钮、信号、面板生命周期、设置页、F4 |

`HotkeyManager` 新增独立于 5 个核心快捷键的「附加快捷键」：单独注册、单独注销，注册失败只在面板里提示，不影响截图等核心快捷键。

## v1 不做

- 追问 / 多轮对话（每次都是独立请求）。
- 历史持久化。
- 完整的公式渲染。
