# Visnip 轻量截图贴图工具设计说明书 v0.3 Compact
日期：2026-06-26
## 1. 本版更新摘要
v0.3 Compact 针对“工具栏高度偏高”的反馈，重新收敛截图工具栏。默认工具栏高度从上一版的 34px 进一步缩小为 30px，按钮从 24px 缩小为 22px，图标视觉尺寸从 16px 收敛为 15px，同时降低阴影强度和边框存在感，让截图时的浮层更轻、更清新、更不遮挡内容。
| 项目 | v0.2 | v0.3 Compact | 说明 |
|---|---:|---:|---|
| 工具栏高度 | 34px | 30px | 默认模式更小巧 |
| 按钮尺寸 | 24px | 22px | 视觉更轻；可保留 26px 安全热区 |
| 图标尺寸 | 16px | 15px | 线条更细、更清爽 |
| 工具栏圆角 | 12px | 9px | 避免胶囊感过强 |
| 阴影 | 中等 | 轻微 | 减少遮挡感 |
| 主色 | #4F6BFF | #4F7CFF | 颜色更清新 |
## 2. 产品定位
Visnip 是一个面向 Windows 的轻量截图与贴图工具。第一版重点不是功能堆叠，而是把“截图、标注、复制、保存、贴图”这条高频链路做到顺滑、准确、少打扰。第二阶段预留 macOS 支持，但 V1 工程以 Windows 为主。
### 设计原则
- 小：工具栏尽量不挡截图内容；状态提示短而清楚。
- 准：选区、放大镜、尺寸、取色和像素微调都要稳定。
- 快：按键路径短，复制/贴图/保存都可以一步完成。
- 原创：参考效率型截图工具的操作范式，但图标、颜色、尺寸、窗口布局和文案全部独立设计。
## 3. 技术选型
| 层级 | 技术 | 用途 |
|---|---|---|
| 主语言 | C++20 | 截图、贴图、窗口和图像处理的性能路径 |
| UI 框架 | Qt 6 Widgets + QPainter | 设置窗口、托盘菜单、截图覆盖层、标注绘制 |
| Windows 捕获 | DXGI Desktop Duplication / Windows Graphics Capture 预研 | 多屏桌面帧捕获和低延迟截图 |
| 窗口能力 | Win32 API | 全局快捷键、无边框置顶、鼠标穿透、DPI 坐标 |
| 图像处理 | QImage + 可替换 Skia/OpenCV | 标注合成、马赛克、缩放、导出 |
| 配置 | JSON / INI | 快捷键、主题、输出路径、贴图偏好 |
C++/Qt 作为 Windows 第一阶段主线更适合截图工具的低延迟窗口能力；macOS 阶段建议保留同一业务状态机和资源系统，仅替换平台服务层。

## 7. 每个功能按钮的详细设计
| 按钮 | 优先级 | 定位 | 交互细节 | 快捷键 |
|---|---|---|---|---|
| 矩形 tool-rect | P0 | 绘制矩形框，默认用于圈出区域。 | 按住 Shift 绘制正方形；拖动对象可移动；属性支持颜色、线宽、圆角、填充透明度。 | R |
| 箭头 tool-arrow | P0 | 指向重点，是截图标注最核心按钮之一。 | 拖拽起点到终点；默认 2px 线宽；拖动端点可微调；支持颜色与粗细。 | A |
| 画笔 tool-pen | P0 | 自由手绘，用于临时圈画和手写说明。 | 抗锯齿、低抖动；滚轮或属性条调线宽；Esc 完成当前笔迹。 | P |
| 文字 tool-text | P0 | 添加说明文字。 | 点击输入，Enter 换行，Ctrl+Enter 完成；默认带轻背景以保证可读。 | T |
| 马赛克 tool-mosaic | P0 | 隐私遮挡。 | 支持矩形拖拽与刷子涂抹两种模式；默认像素块 8px；输出前直接烘焙到图像。 | M |
| 序号 tool-number | P1 | 教程类截图的一键步骤标记。 | 连续点击自动递增；拖动可重排；支持圆形/胶囊样式；默认使用主色。 | N |
| 撤销 action-undo | P0 | 撤销上一步标注操作。 | 与 Command 栈绑定；Ctrl+Z；无步骤时置灰。 | Ctrl+Z |
| 重做 action-redo | P0 | 恢复被撤销的标注操作。 | Ctrl+Shift+Z / Ctrl+Y；无步骤时置灰。 | Ctrl+Y |
| 贴图 action-pin | P0 | 把当前截图直接生成桌面置顶贴图。 | 点击后退出截图层并创建 PinWindow；保持标注结果；默认 100% 透明度。 | P |
| 保存 action-save | P0 | 保存到文件。 | 默认保存到配置目录；Ctrl+S；支持另存为；保存后可选择是否退出。 | Ctrl+S |
| 复制 action-copy | P0 | 复制截图到剪贴板。 | Enter / Ctrl+C；默认 PNG；复制后自动退出可配置。 | Enter |
| 关闭 action-close | P0 | 取消截图或关闭当前工具栏。 | Esc；若有标注未输出，直接丢弃但不弹窗，保持轻量。 | Esc |
## 8. 二级工具与暂缓项
椭圆、高亮、取色器固定、放大镜开关、属性条固定等低频项不进入默认工具栏。后续可以用“更多”按钮或右键菜单承载，但 V1 默认不展开，保持 30px 主工具栏清爽。
## 9. 截图流程
1. 用户按 F1 进入截图遮罩。
2. 系统捕获当前所有屏幕，建立虚拟桌面坐标。
3. 用户拖拽生成选区，可用方向键像素级微调。
4. 选区完成后显示 30px Compact 工具栏。
5. 用户标注后，可 Enter 复制、Ctrl+S 保存、P 贴图或 Esc 取消。
## 10. 贴图功能设计
| 行为 | 设计 |
|---|---|
| 创建贴图 | 从截图工具栏点击“贴图”或按 P；从剪贴板按 F3。 |
| 移动 | 左键拖拽窗口主体。 |
| 缩放 | 鼠标滚轮，以光标所在点为缩放中心。 |
| 透明度 | Ctrl + 滚轮调透明度，范围 20% - 100%。 |
| 鼠标穿透 | Ctrl+T 切换；穿透状态提供边缘提示。 |
| 关闭 | Esc 或右键菜单关闭。 |
| 保存/复制 | 右键菜单提供复制、保存为。 |
## 11. 设置窗口调整
设置窗口保留“常规、界面、截图、贴图、输出、快捷键、关于”七个一级项。界面页新增“工具栏尺寸：紧凑 30px”，默认启用。界面页只展示少量高频参数，避免 Capturer 式复杂配置。

## 15. 资源包说明
本包提供 SVG 源文件、浅色/深色/强调色主题 SVG、多尺寸 PNG、22px 按钮状态切图、QSS、qrc 和 JSON 设计令牌。正式 Qt 工程建议优先使用 SVG 源文件并用主题色渲染，PNG 主要用于原型、文档和低成本预览。
## 16. 合规与原创说明
Visnip 可以学习截图工具的通用操作方式，但不复制 Snipaste 或 Capturer 的代码、图标、图片、文案、资源和像素级 UI。v0.3 的图标、颜色、尺寸、工具栏比例、设置页和菜单视觉均为重新设计。
